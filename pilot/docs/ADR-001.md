# ADR-001: credential-free neutral pilot

## Decision

Use a small status dashboard with SQLite persistence as the neutral pilot.

## Rationale

Available owner repositories include finance/trading scope or Telegram/customer data and are excluded by the acceptance policy. The neutral pilot exercises staging, health, persistence, and rollback mechanics without requiring secrets or irreversible integrations.

## Reversibility

The pilot is isolated in its own Compose project and can be removed without touching the factory controller state.
